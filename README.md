# Family Money

Look-only jars for Ella and Luca. Each child has a separate page, so one bookmark cannot open the other child’s jars.

Spend and Save show sample dollars. Grow shows progress only — no college or later dollar totals. Tips stay on each jar. Nothing here moves money.

## iPad bookmarks

- Ella: https://genemagg10.github.io/kid-money/ella/
- Luca: https://genemagg10.github.io/kid-money/luca/

Site files are on `main` at the repository root (`.nojekyll`, so Pages serves the files as-is). In the repo, set Pages to **Deploy from a branch**, branch `main`, folder `/` (root).
