# Family Money — curriculum for this app

Ella is 8. Luca is 10. Each child has one page (`/ella/`, `/luca/`). No sibling switch, compare, or scores.

This note is the jar map and Phase 1 lesson list for anyone changing the app. An older three-jars table that put Spend and Save on the same Wells balance is not the live model.

## Jar map

| Jar | What the page shows |
|---|---|
| **Spend** | Piggy bank. The child counts it and can edit the total. A slider splits ready-now (brown) and wait (blue). Money owed a grown-up is noted here. |
| **Save** | Wells Fargo savings. Read-only dollars. The slider and anything owed do not change this number. |
| **Grow** | College path as progress only (no dollar total). Retirement path as progress only (Roth IRA now, 401(k) later — named in the retirement tip, never as a balance). Brokerage dollars under Invested / Growing. |

Kid copy stays in plain words. “Wells Fargo” lives in this note and the README, not on the jar cards.

Out of scope: allowance, interest, transfers, market percentages, Phase 2 and Phase 3 screens.

## Lessons

One at a time. The next one unlocks after this one is noticed. No streaks.

| | Lesson | Where it is practiced |
|---|---|---|
| L1 | Three jars — Spend, Save, and Grow | Home Why lines, and a sort on the lesson card |
| L2 | Your dashboard — name and each jar | Home, and a find-these check on the lesson |
| L3 | This month — notice a change or no change | Save → This month |
| L4 | Save vs Spend — ready now, or wait | Spend piggy count and slider |
| L5 | Grow for later — college path and retirement path, grown-ups help, no dollar totals on those paths | Grow |
| L6 | Privacy — jars are not a contest | Lesson card |

Home shows the current lesson and a count such as 2 of 6. Tips and Why lines teach the same jobs in place.

## Saved on this iPad

| Key | What |
|---|---|
| `family-money-learn:ella` / `:luca` | `done`, `notes`, `waitingFor` |
| `family-money-piggy:ella` / `:luca` | Count and slider split |
| `family-money-owed:ella` / `:luca` | Money owed |
| `family-money-parent` | 4-digit parent code for this iPad |

The parent code is a gate so lesson controls stay off the kid path. It is not a bank login. Clearing site data on the iPad removes it. Parent can mark only the next lesson done, and can leave a note, for the child whose page is open.
