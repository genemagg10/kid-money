# Age unlock — same skeleton, more glass (1 page)

**Principle:** Do not redesign. Unscrew the jar lids. Phase 1’s three jars + who-toggle stay the spine through teens.

## ~8–10 (Phase 1 — now)

- Home: greeting + three jar cards (amount + short label).
- Detail: one sentence + optional calm month list.
- Grow: friendly name only (“For college later”).
- No charts, no rates, no account type names.
- Kid UI is **look, not act**.

## ~11–13 (unlock glass, keep bones)

Add **into the same screens**, not new apps:

| Unlock | Where it lands | Still hidden |
|---|---|---|
| Simple goal on Save (“Bike · $40 of $120”) | Save detail + thin progress on home card | Interest math |
| “Grew this year · about $X” one line | Grow detail only | Benchmarks, tickers |
| Month as 2–3 labeled rows | Existing This month | Pie charts |
| Optional split under Grow | Two labeled rows (college / later) | 529 / Roth words |
| Soft “ask parent” for a goal idea | Sheet / note | Peer compare |

Visual system unchanged: same cards, denser type hierarchy, one extra line per card max.

## Teens (more detail, still one place)

| Unlock | Where | Guardrails |
|---|---|---|
| Small line chart (balance over 12 mo) | Grow (and maybe Save) — one chart max per screen | No trading UI |
| Contribution vs growth split | Grow detail | No “beat the market” copy |
| Named goals list (2–3) | Save | No debt products |
| Plain glossary on long-press | “What is this?” | Real jargon only behind kid-safe names |
| Parent-approved “practice allocate” | Separate mode, not default home | Still no live brokerage from kid profile |

Home remains three jars. Charts never replace the big number.

## What never unlocks on the kid profile

- Sibling net-worth ranking or comparison cards  
- One-tap spend / transfer  
- Account numbers, routing, tax forms  
- Fear/urgency (“you’re behind”)  

Those stay in Warren’s parent / curriculum layer.

## Handoff

Warren owns when each unlock fires (age, readiness, or parent toggle). Dieter keeps visual density rules so ~11 and teen feel like the same product with clearer glass — not a new skin.
